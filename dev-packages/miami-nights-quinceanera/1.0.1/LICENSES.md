# Miami Nights — asset provenance

Original HTML, CSS and SVG artwork created for Quinvite (the palms, gown and suit silhouettes are hand-drawn vector art, generated programmatically). Original AI-generated skyline artwork created with OpenAI image generation; no third-party brands, logos or licensed characters. Use and redistribution within Quinvite are intended; no exclusive copyright claim is made for AI-generated material. Event photographs and music are supplied by the organizer, not bundled.

- assets/fonts/bebas-latin.woff2 — SIL OFL 1.1
- assets/fonts/pinyon-latin.woff2 — SIL OFL 1.1
- assets/img/deco-divider.svg — Quinvite project use
- assets/img/dress.svg — Quinvite project use
- assets/img/palms.svg — Quinvite project use
- assets/img/skyline.webp — Quinvite project use
- assets/img/suit.svg — Quinvite project use
